# پوشه داده

| فایل | چه چیزی داخلش است | عمومی؟ |
| --- | --- | --- |
| `store.json` | تمام لیست موجودی، اطلاعات فروشگاه و تاریخچه | ✅ بله — همین فایل توسط سایت خوانده می‌شود |
| `site.json` | آدرس مخزن و شاخه (تنظیمات اتصال) | ✅ بله |
| `vault.json` | توکن گیت‌هاب، **رمزگذاری‌شده** با رمز مدیر | ✅ بله — بدون رمز قابل استفاده نیست |

## نکته امنیتی

- **هیچ‌وقت** توکن خام یا جفت «رمز ← توکن» را در این پوشه یا هر جای مخزن نگذارید.
- `vault.json` فقط با اجرای صفحه‌ی `/setup/` یا ابزار `tools/make-vault.mjs` ساخته می‌شود.
- فایل‌های حساس محلی (مثل `local.secret.json`) در `.gitignore` هستند و هرگز کامیت نمی‌شوند.
- اگر توکن لو رفت، در گیت‌هاب آن را Revoke کنید و از صفحه راه‌اندازی توکن تازه بسازید.

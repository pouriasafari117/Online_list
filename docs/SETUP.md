# راهنمای راه‌اندازی گام‌به‌گام

این راهنما برای کسی نوشته شده که می‌خواهد یک‌بار همه‌چیز را درست کند و بعد
فقط با یک رمز، موجودی فروشگاه را به‌روز نگه دارد.

زمان لازم: حدود ۱۰ دقیقه.

---

## پیش‌نیاز

- یک حساب GitHub (رایگان).
- یک مرورگر مدرن (Chrome، Edge، Firefox یا Safari ۱۶+).
- تصمیم درباره‌ی نام رمز. **این رمز، کلید مدیریت سایت شماست.**

---

## گام ۱ — انتشار سایت

1. مخزن را فورک کنید: `pouriasafari117/Online_list`
2. در مخزن خودتان: **Settings → Pages**
3. در بخش *Build and deployment*:

   | گزینه | مقدار |
   | --- | --- |
   | Source | **GitHub Actions** |

4. به تب **Actions** بروید و منتظر بمانید ورک‌فلو *Deploy to GitHub Pages* سبز شود.
5. آدرس سایت: `https://<username>.github.io/Online_list/`

> **جایگزین بدون Actions:** *Source → Deploy from a branch → main / (root)*.
> سایت هیچ مرحله Build ندارد و همان فایل‌ها سرو می‌شوند.

---

## گام ۲ — ساخت توکن

1. به [ساخت توکن Fine-grained](https://github.com/settings/personal-access-tokens/new) بروید.
2. **Token name**: `Online List`
3. **Expiration**: ۹۰ روز (یا بیشتر). تاریخ را یادداشت کنید.
4. **Repository access** → *Only select repositories* → مخزن `Online_list`
5. **Permissions → Repository permissions → Contents: Read and write**
6. **Generate token** و مقدار `github_pat_...` را کپی کنید.

> ⚠️ این رشته فقط یک‌بار نمایش داده می‌شود. اگر گم شد، توکن را Revoke کنید و
> یکی تازه بسازید.

---

## گام ۳ — سینک توکن با رمز

### روش آسان (مرورگر)

1. آدرس `<آدرس سایت>/setup/` را باز کنید.
   - در پیش‌نمایش محلی: `http://localhost:8080/setup/`
2. توکن را در فیلد اول بگذارید.
3. مالک/مخزن/شاخه معمولاً خودکار پر می‌شود؛ بررسی کنید.
4. **بررسی اتصال و دسترسی** را بزنید. باید چهار مورد سبز ببینید:
   - مخزن در دسترس است
   - دسترسی نوشتن تأیید شد
   - شاخه آماده است
   - توکن معتبر است
5. رمز مدیریت را وارد کنید (حداقل ۱۰ کاراکتر، ایده‌آل: یک عبارت طولانی).
6. **ساخت فایل امنیتی** → **نوشتن در مخزن گیت‌هاب**

صفحه‌ی موفقیت را که دیدید، به سایت برگردید. تمام.

### روش خط فرمان (بدون عبور توکن از مرورگر)

```bash
node tools/make-vault.mjs --owner <username> --repo Online_list --branch main
```

سپس:

```bash
git add data/vault.json data/site.json
git commit -m "راه‌اندازی امنیتی Online List"
git push
```

## گام ۴ — اولین ورود

1. سایت را باز کنید.
2. دکمه **ورود مدیر** (بالا، کنار آیکون‌ها).
3. رمزی را که تعیین کردید وارد کنید.
4. نوار مدیریت پایین صفحه ظاهر می‌شود:

   | دکمه | کار |
   | --- | --- |
   | وضعیت (نقطه) | «همگام با مخزن» یا «منتشرنشده» |
   | انتشار | نوشتن تغییرات در `data/store.json` |
   | + | دستگاه یا دسته جدید |
   | چرخ‌دنده | تنظیمات فروشگاه، رمز و توکن، پشتیبان |
   | قفل | خروج و پاک کردن توکن از حافظه |

---

## گام ۵ — پر کردن لیست

### دسته‌بندی‌ها

هر دسته، «عنوان مشخصات» خودش را دارد. مثلاً:

- **موبایل**: حافظه داخلی، رم، رنگ، سلامت باتری، سیم‌کارت
- **لپ‌تاپ**: پردازنده، رم، حافظه، گرافیک، نمایشگر، سیستم‌عامل
- **کنسول بازی**: نسخه، حافظه، ریجن، دسته همراه

برای هر عنوان می‌توانید **واحد** بگذارید (گیگابایت، اینچ، ٪) و تعیین کنید که
در ردیف لیست کنار نام دستگاه دیده شود یا فقط داخل جزئیات.

### دستگاه‌ها

- **نام**: همان چیزی که مشتری می‌شناسد («آیفون ۱۶ پرو مکس ۲۵۶ گیگ»).
- **قیمت**: خالی یا صفر → «استعلام قیمت».
- **موجودی**: عدد صفر → «ناموجود»؛ ۱ و ۲ (قابل تنظیم) → «کمیاب».
- **پنهان**: دستگاه را آماده می‌کنید ولی هنوز نمایش داده نمی‌شود.
- **ویژه**: در ردیف «پیشنهادهای این هفته» بالای صفحه می‌آید.

### انتشار

هر بار که تغییر می‌دهید، شمارنده‌ی «منتشرنشده» فعال می‌شود. با دکمه **انتشار**
یک کامیت با پیام دلخواه ساخته می‌شود و «آخرین به‌روزرسانی مدیر» روی سایت به‌روز می‌شود.

میان‌بر: `Ctrl/⌘ + S` از هر جای پنل.

## عیب‌یابی

| نشانه | احتمالاً | راه‌حل |
| --- | --- | --- |
| «توکن معتبر نیست» | توکن منقضی یا اشتباه است | توکن تازه بسازید و از «رمز و توکن» جایگزین کنید |
| «دسترسی توکن کافی نیست» | Contents روی Read-only است | توکن را ویرایش یا دوباره بسازید |
| «مخزن یا مسیر پیدا نشد» | مالک/مخزن اشتباه در `data/site.json` | مقدار را درست کنید و دوباره ذخیره کنید |
| «رمز نادرست است» ولی مطمئنید درست است | رمز در دستگاه دیگری عوض شده | رمز فعلی را از صاحب سایت بپرسید یا vault را بازنشانی کنید |
| تغییرات روی سایت دیده نمی‌شود | کش GitHub Pages / سرویس‌ورکر | دکمه به‌روزرسانی (🔄) در لیست، یا `Ctrl+Shift+R` |
| سایت قدیمی می‌ماند | Pages هنوز دیپلوی نکرده | ۱ دقیقه صبر کنید، تب Actions را چک کنید |
| «رمزنگاری در دسترس نیست» | صفحه روی HTTP باز شده | از HTTPS یا `localhost` استفاده کنید |

## بازنشانی رمز

اگر رمز را فراموش کردید:

1. یک توکن جدید بسازید (یا همان توکن قبلی را اگر دارید استفاده کنید).
2. `<آدرس سایت>/setup/` را باز کنید.
3. توکن + رمز جدید را وارد کنید.
4. «نوشتن در مخزن» را بزنید — `data/vault.json` بازنویسی می‌شود.
5. با رمز جدید وارد شوید.

> توکن قبلی در این حالت در فایل جدید ذخیره نمی‌شود؛ اگر توکن تازه ساخته‌اید،
> توکن قبلی را در GitHub **Revoke** کنید.

---

## انتقال لیست به فروشگاه دیگر

فایل `data/store.json` خودکفاست. برای راه‌اندازی یک فروشگاه جدید:

1. مخزن جدید بسازید و همین پروژه را کپی کنید.
2. `data/store.json` را با فایل فروشگاه قبلی جایگزین کنید (از تنظیمات: نسخه پشتیبان → دانلود).
3. `data/site.json` را با مالک و مخزن جدید به‌روزرسانی کنید.
4. صفحه راه‌اندازی را با توکن مخزن جدید اجرا کنید.

هر فروشگاه، vault و رمز مستقل خودش را دارد.
